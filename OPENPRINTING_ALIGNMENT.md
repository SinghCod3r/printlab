# OpenPrinting Alignment

PrintLab is designed specifically to align with current and future OpenPrinting initiatives, particularly the transition to CUPS 3.x and the GSoC projects focusing on automated print testing.

## Existing OpenPrinting Components

### CUPS 3.x
- **Repository**: `OpenPrinting/cups`
- **Purpose**: The core printing system, moving towards an all-IPP, driverless architecture.
- **PrintLab Role**: PrintLab tests target specific CUPS versions to track regressions between releases.
- **Status**: The prototype simulates test results across CUPS 2.4.x and 2.5.x.

### Printer Simulators (go-mfp)
- **Repository**: Various (GSoC projects)
- **Purpose**: Simulating physical printers over the network to allow CI/CD without hardware.
- **PrintLab Role**: PrintLab treats Simulators as a core entity. Tests are orchestrated against specific simulator profiles (e.g. `sim-hp-laserjet`).
- **Status**: The prototype lists simulated capabilities. A real integration would query the simulator manager for active profiles.

### Image Evaluation Pipeline
- **Purpose**: Comparing rasterized output against known-good PDFs to detect visual regressions.
- **PrintLab Role**: PrintLab ingests the metrics (SSIM, PSNR) and difference images generated by the evaluation pipeline.
- **Status**: The prototype serves deterministic fixture images (`expected.svg`, `actual.svg`) and synthetic SSIM/PSNR scores to demonstrate the UI.

### libcupsfilters & libppd
- **Repository**: `OpenPrinting/libcupsfilters`, `OpenPrinting/libppd`
- **Purpose**: Core data format conversion and legacy PPD support.
- **PrintLab Role**: PrintLab tracks regressions back to suspected component changes in these libraries.
- **Status**: Real repositories are linked and mapped in the ecosystem explorer.

## The Testing Pipeline (GSoC 2025/2026)
PrintLab is the web frontend proposed for the "Full Print System Testing Pipeline" discussed in recent OpenPrinting GSoC planning. It sits at the very top of the stack, consuming the JSON results produced by the underlying Go/Python test runners.
